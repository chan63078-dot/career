# IT·AI 진로적성검사

학생이 5점 척도 87문항(기초 소양 30 · 분야 적합도 41 · 과목 8 · 관심 분야 8)에 답하면
성향 6가지, 기초 소양 4영역, 학원 과정으로 취업할 수 있는 IT·AI 직무 16개 중 잘 맞는 TOP 3를 보여 주는 웹 검사입니다.
결과는 구글 시트에 쌓이고, `/admin` 관리자 페이지에서 학생별로 볼 수 있어요.

```
index.html          학생 검사 페이지
admin/index.html    관리자 페이지 (주소 끝에 /admin)
assets/data.js      문항 · 직무 · 점수 계산 (문구나 가중치는 여기서 수정)
assets/config.js    저장 주소(API_URL), 학원 이름, 개인정보 보유 기간
apps-script/Code.gs 구글 시트 저장 서버 (Apps Script)
```

## 1. 구글 시트 + Apps Script 준비 (한 번만)

1. 구글 드라이브에서 새 스프레드시트를 만들어요. (예: `진로적성검사 결과`)
2. 메뉴 **확장 프로그램 → Apps Script**를 열어요.
3. 기본 `Code.gs` 내용을 지우고 이 저장소의 `apps-script/Code.gs`를 통째로 붙여 넣고 저장해요.
4. 왼쪽 **프로젝트 설정(톱니바퀴) → 스크립트 속성 → 속성 추가**
   | 속성 | 값 | |
   |---|---|---|
   | `ADMIN_PASSWORD` | 관리자 비밀번호 (다른 곳에서 쓰지 않는 긴 비밀번호) | 필수 |
   | `NOTIFY_EMAIL` | 새 검사 알림을 받을 메일. 여러 명이면 쉼표로 구분 | 선택 |
   | `ADMIN_URL` | 알림 메일에 넣을 관리자 페이지 주소 | 선택 |
5. 편집기 위쪽 함수 선택에서 `setup`을 고르고 **실행** → 권한 승인.
   - 시트에 `results` 탭과 머리글이 생겨요.
   - 보유 기간(1년)이 지난 결과를 매일 새벽 3시에 지우는 트리거가 등록돼요. (왼쪽 ⏰ 트리거 메뉴에서 확인)
   - 알림 메일 권한도 함께 승인돼요.
6. **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해요.

> Code.gs를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영돼요. URL은 그대로예요.

## 2. 저장 주소 연결

`assets/config.js`의 `API_URL`에 위에서 복사한 웹 앱 URL을 넣어요.

```js
API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec',
```

## 3. GitHub Pages로 올리기

1. GitHub에서 새 저장소를 만들고 이 폴더 내용을 그대로 올려요.
2. 저장소 **Settings → Pages → Branch: main / (root) → Save**
3. 1~2분 뒤 주소가 생겨요.
   - 학생용: `https://<아이디>.github.io/<저장소>/`
   - 관리자: `https://<아이디>.github.io/<저장소>/admin/`

## 기능

- **결과지 인쇄:** 학생 결과 화면과 관리자 상세 화면의 [결과지 인쇄]로 A4 결과지를 인쇄하거나 PDF로 저장해요. 관리자에서 인쇄하면 상담 메모와 담당 멘토가 함께 찍혀요.
- **상담 상태 · 담당 멘토:** 관리자 상세 화면에서 신규 → 연락 완료 → 상담 완료 → 등록 / 보류로 바꾸고 담당 멘토를 적어요. 상태 목록은 `assets/data.js`와 `Code.gs`의 `STATUSES`에서 함께 바꿔요.
- **새 검사 알림 메일:** `NOTIFY_EMAIL`을 넣으면 학생이 검사를 마칠 때마다 메일이 와요. 메일에는 이름 · 소속 · 1~3위 직무만 들어가고 연락처 · 생년월일은 넣지 않아요. 개인 Gmail 계정은 하루 100통까지 보낼 수 있어요.
- **응답 확인 필요 표시:** 80% 이상 같은 번호를 골랐거나, 25문항 이상 같은 번호를 연속으로 골랐거나, 4분 안에 끝낸 결과에 표시가 붙어요.
- **자동 삭제:** 검사일로부터 `RETENTION_DAYS`(365일)가 지난 결과를 매일 지워요. 기간을 바꾸면 `assets/config.js`의 `RETENTION` 문구도 함께 바꿔 주세요.

## 알아 둘 점

- `/admin` 주소는 누구나 열 수 있지만, 결과 목록은 비밀번호가 맞아야만 내려와요. 비밀번호를 10번 틀리면 10분 동안 잠겨요.
- 학생 응답은 저장이 끝나면 그 기기에서 지워져요. 학원 공용 PC · 태블릿에서도 다음 학생이 이전 정보를 볼 수 없어요.
- 학생 화면 주소 끝에 `?demo`를 붙이면 "예시 응답" 버튼이 나와요. 시연용이라 실제로 저장되니, 끝나면 관리자 페이지에서 지워 주세요.
- 관리자 페이지의 **예시 데이터로 화면 미리보기**는 저장소와 상관없는 가짜 데이터예요.
- 개인정보 보유 기간 문구는 `assets/config.js`의 `RETENTION`에서 바꿀 수 있어요. 학원 개인정보 처리방침과 맞춰 주세요.
- 누구나 저장 주소로 결과를 보낼 수 있는 구조라서, 장난 제출이 들어오면 관리자 페이지에서 삭제하면 돼요.
- 문항을 추가하거나 순서를 바꾸면 `Code.gs`의 `ANSWER_COUNT`도 같이 바꾸고 다시 배포해야 해요. 이전 버전으로 저장된 결과는 상세 분석을 다시 계산하지 못해요.
